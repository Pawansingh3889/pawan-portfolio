Governed Agent Stack

_02

sql-steward

Code · Live demo

The flagship of the stack: one governed MCP server where the agent never writes SQL. Every query is compiled from a semantic layer you control (entities, joins, metrics, PII tags), so there is no run_sql tool to misuse. Blocked PII is refused before the query runs, declared data-quality checks gate the results, and init --from-db drafts a reviewable layer from a live schema so it scales past a toy database. Same tools across SQL Server, Postgres, and SQLite; query-warden, pii-veil, and agent-blackbox wire in as optional layers.

semantic layer · no raw SQL · init --from-db · data-quality checks · 3 engines
PythonFastMCPsqlglotSQLAlchemy
_03

FloorMind

Code · Docs

On-prem natural-language-to-SQL over manufacturing data. A LangGraph agent turns plain English into a schema-validated query and answer in seconds, served by a local LLM via Ollama. One governed path: a validation gate, a self-correcting repair loop that feeds errors back to the model, and a tamper-evident agent-blackbox ledger that records the model and prompt behind every answer. Eval score tracked per release, not vibes.

_04

agent-blackbox

Code

An append-only, hash-chained ledger that gives AI agent actions a tamper-evident audit trail. Each row stores the hash of the row before it, so any edit after the fact breaks the chain and verify() points at it. Optional HMAC keying. On-prem, zero dependencies, a single SQLite file.

#01 3f9c… #02 a71e… #03 0b4d… chain broken ✗
Hover a block to edit it, and every block after it breaks.
hash-chained · tamper-evident · HMAC option · zero deps
PythonSQLiteSHA-256

How I work

Three honest stages — same flow whether the work is a pipeline, a dashboard, or shipping a tool to PyPI.

01

Discovery

Read the source. Read the data. Talk to the people who actually run the line. Confirm the problem is the problem before writing code.

02

Architecture

Sketch the smallest thing that delivers value. Pick boring, well-documented tools. Write the tests first when the contract matters.

03

Delivery

Ship in CI behind a green build. Document the trade-offs. Set up a way for the next person (sometimes me) to understand it without paging me.
